# Fran:D 족발 원가 인텔리전스

프랜차이즈 본사 미팅용 9개 챕터의 독립 실행형 HTML 데모.

## Build

```bash
python3 src/build_data.py
node --check src/app.js
```

`index.html`에 CSS, JS, 데이터가 모두 포함된다. 외부 스크립트·폰트·네트워크 조회 없이 로컬 파일로 열 수 있다.

## Data

- 관세청 국가별 수입: 2021-01~2026-09, 양의 수입중량 688개 국가·월.
- Foodtech DB: 같은 기간 3,249건. True USD와 거래일 주간 수입 과세환율로 환산한 KRW를 사용.
- 가격 이상 거래 1건은 가격 집계에서 제외하고 공급망 중량에는 유지.
- 수입사 비교: 건당 10,000kg 이상, 선택 국가·월·공급사별 수입사 2건·20,000kg 이상.
- 월 30톤, 납품가 반영률, 시차와 절감액은 명시된 시나리오 입력값.
- 준비중량 환산: 마왕통구이 소 410g, 중 560g, 대 680g(레시피 범위의 중간값).

`src/data.json`은 이 분석 시점의 거래 필드와 합산 원자료를 보존한다. 신규 데이터 제공 시 스냅샷과 본문 기간·헤드라인을 함께 갱신한다.
